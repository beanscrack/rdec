# rdec

A from-scratch x86-64 machine-code -> C decompiler, in Rust. The goal is output
that is *demonstrably* equivalent to the code it came from, not output that looks
plausible.

`ROADMAP.md` is the contract: every milestone is gated by commands, and a
milestone is closed by running them. `docs/ir-semantics.md` defines what the IR
means; `crates/core/src/interp.rs` is that document in Rust and is the reference
translation validation compares passes against.

![gates](https://github.com/beanscrack/rdec/actions/workflows/ci.yml/badge.svg)

## The checks

```bash
cargo run -q -p rdec-cli -- status   # the whole table, generated by running the gates
cargo run -q -p rdec-cli -- flags    # T1: the flag model vs real EFLAGS on this CPU
cargo run -q -p rdec-cli -- selftest # the IR verifier must be able to fail, on the right things
cargo run -q -p rdec-cli -- corpus   # clang corpus + hashed manifest
cargo test                            # B1-B7 fixtures, TV, sabotage detection
```

`flags --full 20000` runs the 9.7-billion-probe sweep (release build, ~6 min).

## Status

M0 (harness + IR semantics) closed: flag model verified against hardware
(9,728,273,400 probes, 0 mismatches), IR interpreter + translation validation,
18 gate fixtures for the audited pass bugs. M1 is load/decode/discovery.

## Layout

| Crate | Role |
|---|---|
| `crates/core` | IR, CFG, passes, flag fusion, interpreter, TV, verifier |
| `crates/arch-x86` | EFLAGS semantics + decoding |
| `crates/verify` | T1 hardware oracle, corpus generator |
| `crates/cli` | the `rdec` command |
